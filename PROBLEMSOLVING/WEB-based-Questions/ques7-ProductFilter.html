Problem: Live Product Search Filter
Problem statement
You are given a list of products displayed on a webpage and a search input field.
Your task is to implement a live search functionality using JavaScript.
As the user types something in the search box, only those products whose names contain the entered text should remain visible. All other products should be hidden.
The filtering should happen dynamically without clicking any search button.
Requirements
1. Initially, all products should be visible.
2. As soon as the user types a character, filter the products.
3. Display only products whose names contain the entered keyword.
4. Filtering should be case-insensitive.
- lap should match Laptop.
- PHO should match Smartphone.
5. If the user deletes some characters, products should be filtered again.
6. If the user clears the input completely, all products should become visible again.
7. If no product matches, display No products found!.
8. Do not remove products from the DOM. Only hide and show them.
