My To-Do List

Problem statement
Create a To-Do List application where users can add tasks, mark tasks as completed, and delete tasks dynamically.
Requirements
1. User should enter a task in the input field.
2. On clicking Add Task, the task should appear in the list.
3. If the input is empty, display an appropriate error message.
4. Each task should have a Complete button.
5. Clicking Complete should mark the task as completed (use strikethrough styling).
6. Each task should have a Delete button.
7. Clicking Delete should remove that particular task.
8. After adding a task, clear the input field.
