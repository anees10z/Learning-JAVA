Password Validation

Problem: Password and Confirm Password Validation

Problem Statement

Create a Password Validation Form containing two input fields:

  1. Password
  2. Confirm Password

The password must satisfy specific validation rules. The confirm password must exactly match the original password.

Requirements

Password Validation

  1. Password length must be exactly 8 characters.
  2. Password must contain only alphanumeric characters (A–Z, a–z, 0–9).
  3. Special characters and spaces are not allowed.
  4. Display an appropriate error message if the password is invalid.

Confirm Password Validation

  1. Confirm Password must be exactly the same as Password.
  2. Matching should be case-sensitive.
  3. If both passwords match, display "Password Matched!".
  4. If passwords don't match, display "Passwords do not match!".
  5. If either field is empty, display an appropriate message.

Dynamic Behaviour

  • Validation should happen as the user types.
  • If the user changes the original password, confirm password should be checked again.
  • Clear old error messages when the input becomes valid.
